# Calculadora de Circuito Passa Baixa
Este aplicativo permite que o usuário calcule os resistores e capacitores necessários para um circuito passa baixa.

Funcionalidades

O usuário insere os seguintes dados:

Amplificação desejada

Capacitor (uF)

Frequência (Hz)

Variação do passo

O aplicativo calcula automaticamente os 3 resistores e o segundo capacitor necessário para o circuito.

É possível limpar todos os campos com um botão.

Como Usar

Insira os valores de amplificação desejada, capacitor, frequência e variação do passo.

O aplicativo calculará automaticamente os resistores e o segundo capacitor.

Clique no botão de limpar para resetar os campos.
